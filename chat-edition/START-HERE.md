# Tutor chat edition: Free-plan test

This is a **test**, to find out whether the tutor can run in a claude.ai Project on
the Free plan. It takes about 30 minutes, most of it one short lesson. Please write
down what happens at each step; that's the whole point.

Use a **Free** claude.ai account, on the website (claude.ai) or the desktop app.
Menu names below may be slightly different from what you see; look for the closest
match.

## 1. Turn things on

In **Settings**, find **Capabilities** and turn on **code execution** (it may be
called "Code execution and file creation"). Then find **Skills** and turn them on.

*Note if either is missing or locked on the Free plan.*

## 2. Add the two skills

In Skills, upload **`tutor-lesson.zip`** and **`tutor-probe.zip`** from this folder.
Upload each zip as it is; don't unzip it. Make sure both are switched on.

## 3. Make the Project

Create a new Project called **My tutor**.

- Add every file from the **`project-files`** folder to the Project's files.
- If the Project has a place for **instructions**, paste in the text of
  `project-instructions.md`.

*Note if Free didn't let you create the Project, add files, or add instructions.*

## 4. Run the probe

Start a new chat in the Project and send: **Run the tutor probe.**

*Save the table it ends with: copy it, or take a screenshot.*

## 5. Check the save-back

Start **another new chat** in the Project and send:
**What does probe-check.md in this project say?**

*Note the answer.* Then delete `probe-check.md` from the Project's files if it's
there.

## 6. Do one real lesson

Start a new chat in the Project and send: **Let's do a tight lesson.** Go through
it to the very end, including its wrap-up questions, until it says it has recorded
the lesson.

*Note:*
- *Did you hit a usage-limit message? If so, about how many messages in?
  (Screenshot it.)*
- *Did it say it saved the files back to the Project, or ask you to do it?*

## 7. Check the lesson stuck

Start one more new chat in the Project and send:
**What's queued next in my tutor, and what does the newest entry in lesson-history.md say?**

*Note the answer. It should describe the lesson you just did.*

## 8. Send back

Send the probe table, your notes from steps 1, 3, 5, 6 and 7, and any
screenshots.
